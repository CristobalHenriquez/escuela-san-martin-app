# 📋 Guía de Trabajo por Equipos - Proyecto Escuela San Martín

## 🎯 Objetivo General
Ayudar a completar el sitio web de la Escuela San Martín. El profesor implementará la parte técnica, pero necesita que los equipos preparen el contenido y materiales necesarios.

---

## 👥 División de Equipos

### 🔧 **EQUIPO 1: APOYO TÉCNICO**
**Responsabilidad:** Ayudar con tareas básicas de programación y testing

### 🎨 **EQUIPO 2: DISEÑO Y IMÁGENES** 
**Responsabilidad:** Crear y recopilar todas las imágenes necesarias

### ✍️ **EQUIPO 3: CONTENIDO Y TEXTOS**
**Responsabilidad:** Escribir todos los textos que van en la web

---

## 🔧 EQUIPO 1: APOYO TÉCNICO

### 📌 **Tareas Simples**

#### **1. Testing y Revisión**
- [ ] **Probar el sitio web en diferentes dispositivos**
  - Abrir la web en celular, tablet y computadora
  - Anotar qué cosas se ven mal o no funcionan
  - Hacer una lista de errores encontrados

- [ ] **Revisar formularios**
  - Probar enviar formularios con datos incorrectos
  - Verificar que los mensajes de error aparezcan
  - Comprobar que se guarden bien los datos

#### **2. Organización de Archivos**
- [ ] **Ayudar a organizar las carpetas**
  - Renombrar archivos con nombres claros
  - Organizar imágenes en las carpetas correctas
  - Crear listas de qué archivos faltan

#### **3. Documentación Básica**
- [ ] **Hacer listas de lo que funciona**
  - Anotar qué páginas ya están listas
  - Listar qué funciones del admin ya funcionan
  - Documentar usuarios y contraseñas de prueba

### 🛠️ **Herramientas que van a usar**
- Navegador web (Chrome, Firefox)
- Bloc de notas para anotar errores
- Explorador de archivos

---

## 🎨 EQUIPO 2: DISEÑO Y IMÁGENES

### 📌 **Tareas Simples**

#### **1. Recopilar Fotos de la Escuela**
- [ ] **Fotos del personal**
  - Sacar fotos del director y subdirectores
  - Fotos de los profesores principales
  - Fotos grupales del personal
  - **Formato:** Cuadradas, buena iluminación

- [ ] **Fotos de las instalaciones**
  - Aulas principales y laboratorios
  - Patio, biblioteca, gimnasio
  - Entrada y fachada de la escuela
  - **Formato:** Horizontales, alta calidad

#### **2. Crear Imágenes Básicas**
- [ ] **Logo simple de la escuela**
  - Usar Canva o herramientas gratuitas
  - Colores: azul y blanco (sugerido)
  - Incluir el nombre "Escuela San Martín"

- [ ] **Banners para secciones**
  - Imagen para "Noticias"
  - Imagen para "Personal"
  - Imagen para "Logros"
  - **Tamaño:** 1200 x 400 píxeles

#### **3. Organizar Contenido Visual**
- [ ] **Preparar imágenes para noticias**
  - 10 fotos de eventos escolares
  - Fotos de actividades deportivas
  - Fotos de actos y ceremonias

- [ ] **Iconos simples**
  - Iconos para contacto (teléfono, email, dirección)
  - Iconos para redes sociales
  - Descargar de sitios gratuitos como Flaticon

### 🎨 **Herramientas Sugeridas**
- **Canva** (gratuito, fácil de usar)
- **GIMP** (gratuito, más avanzado)
- **Cámara del celular** (para fotos nuevas)
- **Unsplash** (fotos gratuitas si necesitan)

### 📁 **Dónde guardar las imágenes**
```
Crear carpetas con estos nombres:
- personal/
- instalaciones/
- noticias/
- logros/
- banners/
- iconos/
```

## ✍️ EQUIPO 3: CONTENIDO Y TEXTOS

### 📌 **Tareas Simples**

#### **1. Información Básica de la Escuela**
- [ ] **Texto de bienvenida**
  - 2-3 párrafos para la página principal
  - Mensaje del director
  - Destacar los valores de la escuela

- [ ] **Historia de la escuela**
  - Cuándo se fundó
  - Logros importantes
  - Cómo ha crecido en el tiempo

#### **2. Información del Personal**
- [ ] **Biografías cortas**
  - Director: nombre, experiencia, estudios (100 palabras)
  - Subdirectores y coordinadores (50 palabras cada uno)
  - Profesores principales (30 palabras cada uno)

#### **3. Contenido para Secciones**
- [ ] **10 noticias de ejemplo**
  - Eventos recientes de la escuela
  - Logros de estudiantes
  - Actividades especiales
  - **Formato:** Título + 2 párrafos

- [ ] **Información de contacto**
  - Dirección completa
  - Teléfonos
  - Email
  - Horarios de atención

#### **4. Textos Informativos**
- [ ] **Servicios que ofrece la escuela**
  - Niveles educativos
  - Actividades extracurriculares
  - Servicios especiales

### ✍️ **Formato de los textos**
- **Archivo:** Word o Google Docs
- **Extensión:** Párrafos cortos y claros
- **Estilo:** Formal pero amigable

### � **Plantilla para Noticias**
```
TÍTULO: [Título atractivo]
FECHA: [DD/MM/AAAA]

PÁRRAFO 1: Qué pasó y cuándo
PÁRRAFO 2: Quiénes participaron y por qué es importante
```

## 🤝 TRABAJO EN EQUIPO

### 📅 **Cronograma Simple (4 semanas)**

#### **Semana 1: Recopilar información**
- **Equipo 1:** Revisar qué funciona en la web actual
- **Equipo 2:** Sacar fotos de la escuela y personal
- **Equipo 3:** Investigar información básica de la escuela

#### **Semana 2: Crear contenido**
- **Equipo 1:** Probar formularios y anotar errores
- **Equipo 2:** Crear logo y banners básicos
- **Equipo 3:** Escribir textos principales

#### **Semana 3: Organizar y completar**
- **Equipo 1:** Organizar archivos y hacer listas
- **Equipo 2:** Completar fotos faltantes
- **Equipo 3:** Escribir noticias de ejemplo

#### **Semana 4: Revisión final**
- **Todos:** Revisar que todo esté completo y bien organizado

### 📋 **Entregas Semanales**
Cada viernes cada equipo debe entregar:
- Lista de tareas completadas
- Archivos o contenido creado
- Problemas encontrados o dudas
